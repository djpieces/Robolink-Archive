Step 1

Before You Fly

PRE-FLIGHT WARNING

Our drones are durable, yet not indestructible. Please exercise caution while piloting your drone. To prolong the longevity of your drone, avoid flying into walls or other objects. Prior to takeoff, please review lesson 0.2 “Before You Fly”.

Step 2

Lesson Overview

This lesson is for learners who have a macOS or Windows device and want to download the official Python distribution. Using Python with an integrated development environment (IDE) like PyCharm will teach industry-relevant skills in program development. This is recommended only if you have experience with text-based programming and would like to explore using a new software with lots of features. This lesson will go over how to:

  • Install Python
  • Install PyCharm Community Edition
  • Set up PyCharm environment and install CoDrone EDU library
Step 3

Python Installation

First, you will need to install Python on your Mac or Windows machine. If you’re using a guest or limited account, make sure you have access to admin credentials for installing new software on the computer. This is especially important for students using a school or parent computer with limited access. If you are on a Mac computer, you may need to modify the security settings in system preferences in order to download software.

Click here to go to the Python website to install the most recent version. Follow along with the instructions in the video below. Regardless of the Python version shown in the video, the instructions will still apply.

Step 4

PyCharm Edu Installation

Next, install PyCharm Community (free) edition, which is what we will use for writing out our Python code and running it on the CoDrone EDU.

Note: If you choose not to use PyCharm and prefer your own editor or IDE, you will need to know how to install packages on your platform of choice. If you are not sure how to do this, we recommend following the tutorial for PyCharm instead.

Click here to go to the PyCharm download page and follow the instructions in the video below.

Step 5

Set Up PyCharm Environment for CoDrone EDU

Now you need to create a new project and set it up with the CoDrone EDU library. Follow along with the video instructions below. In the tutorial, you will need to copy and paste the import statement into the generated main.py.

Note: If a main.py file was not generated, you can make a new one by right-clicking on the project name and selecting “New>Python File”. This is for both Windows and Mac.

Step 6

Connect the Controller

In order to program your CoDrone EDU from any platform, you will need to connect your controller to your device using the cable that came with your CoDrone EDU. It is important that you use this cable because it is designed to transfer data. Not all USB cables are capable of transferring data.

Once plugged in, if your drone does not switch to LINK state, you may have the wrong cable or the cable may be broken.

Step 7

Power On the Drone

Next, power on the drone using a charged battery.

Your drone should pair to the controller, as indicated by the solid LED on the drone and controller. If your drone and controller are not paired, watch this video.

Step 8

Running Code in PyCharm

To get familiar with PyCharm, print “Hello, World!” by typing it in the code editor. You can also copy and paste this code:

print("Hello, world!")

To run the code, press the green triangle icon at the top-left of your code editor.

PyCharm will automatically save your file when your program is run, but you can save periodically by pressing CTRL + S on your keyboard.

Note: If you have been working on multiple files, using this button may run a different file, even if you don’t have it open. Always check that the name of the file next to the green “run” icon is the name of the file that you want to run.

If you are having trouble running the correct file, another way is to right-click inside the coding area and run the selected file.

In the next step, you will learn how to run a Python program with the CoDrone EDU library.

Step 9

Console Window

When you run the code, any outputs or errors will appear in the console at the bottom of the screen. The Python console is helpful for debugging, or finding errors in your code. You can use the print() function to print out values and test whether your programs are running correctly. You will be using the print statement more in the next lessons.

Step 10

Running Code with CoDrone EDU

In this step, you will run a test program with CoDrone EDU. Don’t worry, the drone will not take off. This example code will demonstrate the lights and sounds! Please note, your drone must be connected for the code to run.

Copy and paste the entire code into PyCharm, then run the program.

from codrone_edu.drone import *



drone = Drone()

drone.pair()

drone.set_drone_LED(255,255,255,255)

drone.drone_buzzer(Note.C4, 1000)

drone.drone_buzzer(Note.D4, 1000)

drone.drone_buzzer(Note.E4, 1000)



drone.close()

Did your drone beep and change colors? Congratulations! You ran your first CoDrone EDU program with PyCharm! As you go through the lessons, notice that every CoDrone EDU program always needs the following lines of code. Your program won’t run without them:

from codrone_edu.drone import *

drone = Drone()

drone.pair()

# Your code goes here

drone.close()
